# Get help

## Read the documentation

The documentation is at [byomailer.com/docs](https://byomailer.com/docs). It explains how to install BYOMailer, connect Amazon SES, send campaigns, and use the REST API, the SDKs and the MCP server.

## Ask a question

Ask questions in the [Q&A category](https://github.com/amedina068/byomailer/discussions/categories/q-a) of the BYOMailer discussions. Do not open an issue for a question.

Before you ask, search the old discussions. In your question, give the version of BYOMailer, the install method and the steps that you did.

## Report a bug or ask for a feature

If the problem is in this SDK, open an issue in [this repository](https://github.com/amedina068/byomailer-ruby/issues/new/choose) with the matching form. If the problem is in the BYOMailer server, open the issue in the [BYOMailer repository](https://github.com/amedina068/byomailer/issues/new/choose).

## Report a security problem

Do not report a security problem in an issue or a discussion. Read [SECURITY.md](SECURITY.md) and report the problem in private.

## Response time

One person maintains BYOMailer, so answers are not immediate. A question with the version, the steps and the full error gets an answer faster.
